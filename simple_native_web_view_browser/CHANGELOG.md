## 0.1.0

- Реализация простого нативного браузера: полноэкранный WebView, панели
  инструментов, адресная строка (скрыта/редактируемая/только чтение),
  кастомный User-Agent, куки (начальные, reloadWithCookies, постоянное/
  эфемерное хранилище), события onLoadStop/onLoadError/onClosed.
- iOS: WKWebView, собственные панели с системными цветами (светлая и
  тёмная тема), UIBarAppearance.
- Android: WebView в отдельной Activity, тема DayNight.
- Интеграционные тесты (example) для обеих платформ.
