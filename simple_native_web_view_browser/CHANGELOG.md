## 0.2.0

- Новые параметры запроса: `enableCookiesAndroid` (только Android: отключение
  приёма кук, восстанавливается при закрытии браузера) и `allowFileAccess`
  (загрузка `file://`, по умолчанию выключена на обеих платформах).
- Безопасность: валидация кук (запрет «;», «,» и управляющих символов),
  блокировка `file://` по умолчанию, жёсткие настройки файлового доступа
  WebView (Android), единственная доставка onSchemeRedirect за сеанс (Android),
  onLoadError только для главного кадра (Android), сброс веб-инспектора при
  повторном открытии без отладки (iOS), игнорирование enableDebugging в
  release-сборках.
- Исправления: ложный onClosed при смене темы Android (uiMode в configChanges),
  зависание open() при неудачной презентации (iOS).
- Внимание: конструктор `SimpleBrowserCookie` теперь валидирует значения и не
  является const.
