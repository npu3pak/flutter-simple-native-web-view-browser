## 0.2.1

- Безопасность: нативная валидация кук (защита от инъекции атрибутов
  при прямом вызове канала).
- Исправления: `reloadWithCookies` применяет куки к текущему адресу
  страницы (а не к стартовому), игнорирование отмены навигации
  (NSURLErrorCancelled) — без ложных onLoadError.

## 0.2.0

- Параметр `allowFileAccess`: блокировка `file://` по умолчанию
  (адреса передаются приложению через onSchemeRedirect).
- Безопасность: сброс веб-инспектора (isInspectable) при повторном
  открытии без отладки.
- Исправление: гарантированный результат open() при неудачной
  презентации (не зависает, не оставляет «застрявшую» сессию).

## 0.1.0

- iOS-реализация: BrowserViewController (панели инструментов, адресная
  строка, куки, события onLoadStop/onLoadError/onClosed), системные цвета,
  адаптация к светлой и тёмной теме.
